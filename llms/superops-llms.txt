# SuperOps

> SuperOps is a unified PSA (Professional Services Automation) and RMM (Remote Monitoring and Management) platform for MSPs and internal IT teams. It exposes a public GraphQL API (separate MSP and IT surfaces, US and EU data centers) for clients, tickets, assets, users, invoices, knowledge base, and service catalog data. Requests authenticate with a bearer API token plus a CustomerSubDomain header and are limited to 800 requests per minute.

## APIs

- [SuperOps MSP GraphQL API](https://developer.superops.com/msp): GraphQL for MSPs — clients, tickets, assets, users, invoices, KB, service catalog. Endpoints: https://api.superops.ai/msp (US), https://euapi.superops.ai/msp (EU).
- [SuperOps IT GraphQL API](https://developer.superops.com/it): GraphQL for internal IT teams — assets, tickets, users, KB, service catalog, IT documentation. Endpoints: https://api.superops.ai/it (US), https://euapi.superops.ai/it (EU).
